# Contributing

Run the app using the README instructions. Report bugs with browser, steps to reproduce, expected behavior and actual behavior. Avoid sensitive data.

For changes, open an issue describing the problem, make a focused branch, run `node --test tests/core.test.cjs`, and manually check desktop and narrow-screen layouts, form editing, preview, reload persistence and YAML export. Add regression coverage for generator or validation changes. Explain behavior and verification in your pull request. Be respectful and constructive.
